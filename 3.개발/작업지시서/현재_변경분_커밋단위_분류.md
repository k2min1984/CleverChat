## 6. 검증 기준

- `3.개발/cleverchat`에서 `.\mvnw.cmd clean test`
- Docker CLI/Testcontainers가 Docker daemon을 감지하는 환경에서 `.\mvnw.cmd -Pit test`
- 루트에서 `git diff --check`

마지막 확인 결과는 2026-05-28 기준으로 `clean test`와 `git diff --check`는 통과했다. 현재 로컬 Docker pipe는 Testcontainers에서 감지되지 않아 `-Pit test`는 Docker 환경 복구 후 재확인한다.
