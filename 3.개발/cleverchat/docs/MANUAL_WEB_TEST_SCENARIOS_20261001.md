## 0. 준비와 메뉴 읽는 법

- 상담: <http://127.0.0.1:8080/chat>
- 관리자: <http://127.0.0.1:8080/admin>
- 관리자 계정: `localadmin`. 비밀번호 위치는 시작 안내에 있다.
- 현재 예제: **로컬 설치 확인 안내**(활성), **로컬 검증 - 시작 노드 없는 초안**(게시 차단 확인용).
- 시험 이름은 `수동검증_`으로 시작한다. 기존 예제를 덮어쓰지 않는다.
- 화면에 `Initial Operator`라고 보여도 계정 ID는 `localadmin`이다. 표시 이름과 권한 역할을 혼동하지 않는다.

| 화면에 적힌 메뉴 | 쉬운 뜻 |
|---|---|
| Scenario list | 상담 순서와 답변 만드는 곳 |
| Chat sessions | 사용자와 나눈 대화 기록 |
| Failure queue | 답을 못 했거나 실패한 대화 |

| Search logs / PII block logs / Popular queries | 검색 기록 / 개인정보 차단 기록 / 인기 검색어 |
| Statistics / Audit logs | 이용 통계 / 관리자가 바꾼 기록 |
| Notices / Notifications | 공지 / 관리자 알림 |
| Code / Menu / Permission management | 분류 코드 / 메뉴 / 권한 관리 |

## B. 상담 운영·검색 기록·통계

## C. 새 상담 시나리오 만들기

기존 예제를 고치지 않고 `수동검증_상담_20261001`을 새로 만든다. 그림처럼 **질문 → 답변 → 종료**의 세 칸을 연결할 것이다. 화면의 ‘노드’는 이 세 칸 중 하나를 뜻한다.

### 입력할 내용

| 칸 | 관리키 | 노드 유형 | 제목 | 챗봇 문구 |
|---|---|---|---|---|
| 첫 질문 | `manual_start` | 질문 | 수동검증 시작 | 무엇을 확인하시겠습니까? |
| 답변 | `manual_answer` | 답변 | 실행 주소 안내 | 검색은 8000번, 상담은 8080번입니다. |
| 종료 | `manual_end` | 종료 | 수동검증 종료 | 수동 테스트를 마쳤습니다. |

| 번호 | 무엇을 누르고 입력하나 | 무엇이 나오면 정상인가 |
|---|---|---|
| CC-24 | **Scenario list** → 제목 `로컬` → **검색**, 상태 `활성` → **검색**, **초기화**. | 제목/상태 조건에 맞는 목록이 나오며 초기화하면 전체 목록으로 돌아간다. |

## G. 크롤링 — 인터넷 자료 가져오기

| CC-71 | 상세 **수집 실행** 한 번 → **새로고침**, **실행 이력** 확인. | 대기→수집 중→완료, 처리 건수/시각/메시지가 나온다. 실행 중 버튼이 중복 실행을 막는다. 사이트 거부/외부 망 문제면 원인을 기록하고 보류; 서버 코드 오류라면 실패. |
| CC-72 | **수집 문서** → 문서 제목 클릭 → 상세 내용/출처 URL 확인. | 공개 페이지의 실제 제목과 본문이 보이고 원문 주소가 맞는다. 검색칸에 제목 일부 입력 → **검색**하면 해당 문서를 찾는다. |
| CC-73 | 상세 **실행 이력 → 페이지별 처리 로그**를 펼친다. | JSON 저장을 켰다면 `JSON 저장 완료`와 실제 경로가 보인다. 탐색기로 그 경로를 열어 JSON 파일도 확인한다. 꺼 둔 상태에서는 파일이 없는 것이 정상. |
| CC-74 | 같은 대상 **수집 실행**을 다시 한 번 → 완료 후 문서·실행 이력 비교. | 실행 이력은 새로 생기되 같은 URL·같은 내용의 문서가 무한히 중복 증가하지 않는다. 중복/갱신 표시를 확인한다. |
| CC-75 | 상담 **새 상담** → 수집 문서 제목의 고유한 단어 입력 → **전송** → 해당 자료 선택. | 수집 내용이나 검색 결과와 출처 링크를 볼 수 있다. AI가 꺼져 있어도 검색 근거 안내는 가능해야 한다. 다른 검색 결과가 섞이면 정확한 제목으로 다시 좁힌다. |
| CC-76 | 대상 **대상 수정** → 이름 끝에 `수정확인` 추가 → 저장 → 재확인. 끝나면 **사용**과 **자동 실행**을 해제하여 저장. | 변경이 유지되고 미사용 대상은 새 수집을 시작하지 않는다. 목록의 사용 여부 필터로 해당 행을 찾을 수 있다. |

웹페이지 본문이 사진뿐인 경우 **사진 속 글자 OCR은 현재 CLEVERCHAT 크롤러 미지원**이다. 제목만 남을 수 있으며, 이를 본문 수집 성공으로 처리하지 않는다. CleverSearch의 업로드 이미지 OCR과 다른 기능이다.

## I. 동우·회사 환경·추가 데이터가 필요한 항목

| 번호 | 준비 및 클릭 순서 | 정상 결과와 판정 |
|---|---|---|
| CC-X01 | **동우 AI 담당자와 함께** 실제 API 기본 주소·모델·인증키 방식 확보. 관리자의 **시스템 설정 → AI 연결**에 주소/모델 입력 → **vLLM 연결 저장 → 저장된 연결 확인**. 연결 성공 후 **AI 답변 사용=사용** 저장 → 근거 문서가 있는 질문을 상담에서 전송. | 모델 목록 접속 성공과 실제 생성 답변·출처를 각각 확인한다. 연결 확인 버튼은 모델 목록 조회이므로 생성 답변 성공까지 보장하지 않는다. 현재 코드는 OpenAI 호환 `/models`, `/chat/completions` 형식 기준. 동우 서버 형식이 다르면 연동 수정 필요로 기록한다. 시험 뒤 원래 사용 여부·주소·모델 복원. |

### 전체 시험 완료 판단

기본 기능은 해당 번호의 실제 결과를 확인한 경우에만 통과다. 조건부 항목은 보류 이유와 필요한 담당자/정보를 적는다. **시스템 설정 화면이 열리고 값이 저장되는 것만으로 동우 AI·회사 SSO까지 완성됐다고 판단하지 않는다.**
