## 설정 우선순위·적용 시점

운영 화면은 `/admin/system-settings`이며 ADMIN만 저장할 수 있다. 운영 모드/경로와 각 설정 영역은 `tb_system_settings`에 저장된다. 같은 버전을 동시에 수정하면 재조회 후 다시 저장해야 한다.

`runtime_settings`에 저장한 항목 → 해당 Spring property/환경 설정 → 코드 기본값 순이다. **DB에 저장한 값을 환경변수만 바꿔 덮어쓸 수 없다.** 환경·property 값은 서비스 생성 시 기본값으로 읽으므로 변경하면 재시작한다. DB 저장값은 다음 요청에 반영되며 캐시를 사용하는 다른 인스턴스에는 약 1초 지연이 있을 수 있다.

크롤링 런타임 값은 작업 시작 시 스냅샷으로 고정되어 다음 작업부터 반영된다. 저장 폴더는 파일 생성 시 해석되며 변경해도 기존 파일이 이동하지 않는다. LOCAL/GATEWAY 전환 및 활성 인증 구성 변경은 기존 세션을 무효화한다. 로그인 세션 유지시간은 다음 요청에 적용한다.

## 기본 시스템 설정

2026-09-29 확인: 신규 설치 시 V20~V23이 `cleverchat_dev`로 search_path를 지정한다. 환경변수만으로 다른 스키마를 선택해 전체 마이그레이션을 실행하지 않는다. 자동 설치는 [README.md](../../README.md)의 고정 스키마 기준을 사용한다.

| 화면 항목 | DB 컬럼 | 기준 |
|---|---|---|
| 독립/연계 | `operation_mode` | 신규 DB 기본 LOCAL. GATEWAY 저장에는 주소·서비스 ID·서버 공유 시크릿 필요 |
| Gateway 주소 | `gateway_url` | 사용자가 연계 로그인으로 이동할 주소. 통합 로그아웃 계약과는 별도 |
| 서비스 ID | `service_id` | 기본 cleverchat, `[a-z0-9-]{1,32}`. 권한 헤더의 동일 ID 항목을 선택 |
| JSON 기본 폴더 | `crawl_export_directory` | 앱 서버 절대 경로. 대상별 별도 경로가 있으면 그 경로 우선 |
| 대상별 JSON 저장 | `tb_crawl_target`의 관련 컬럼 | 저장 여부는 대상 단위. 저장 ON인데 대상/시스템 경로가 모두 비어 있으면 불가 |

## 해석 시 주의할 차이

- `SEARCH_POOL >= SEARCH_DISPLAY`여야 저장된다. 현재 검색은 최소점수/상대 관련도/표시 상한을 항상 적용하며, 모두 미달이라고 1건을 강제로 보여주지 않는다. 일부 enum/화면 도움말의 과거 표현은 [미결 사항](../06.인수인계/인수검수_미결사항.md)에 기록했다.
- `CHAT_HISTORY_DAYS`는 조회 범위다. 대화 DB의 자동 삭제는 별도 코드에 고정된 90일 기준이며 이 값을 늘려도 삭제가 중단되지 않는다.
- 크롤링 제한 0은 무제한이다. 대상 사이트·데이터량·실행 시간을 고려해 설정한다.
- AI 기본 주소는 `/v1`까지 입력한다. AI를 켜려면 주소와 모델명 모두 필요하며 API 키는 화면/DB가 아닌 서버에서 지정한다.
- 정리 설정 저장 자체는 삭제를 실행하지 않는다. JSON 자동 정리는 기본 OFF이고 등록 이력·원래 경로·내용 해시가 일치하는 파일만 대상으로 한다.
