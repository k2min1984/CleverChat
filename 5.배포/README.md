## 배포 환경 (요약)

| 환경  | 호스트 | DB | HTTPS | 비고 |
|-------|--------|----|----|------|
| dev   | 개발자 로컬 | Docker PostgreSQL (5433) | 미사용 | 개발용 |
| stage | 검증 서버 | 물리 PostgreSQL | nginx 종단 | 검증 |
| prod  | 운영 서버 | 물리 PostgreSQL | nginx 종단 | 본번 |

## 운영 원칙
- 배포 산출물(JAR)은 별도 저장소·디렉토리에서 버전 관리. 운영 서버 직접 빌드 금지.
- 시크릿은 코드/문서에 평문 금지. 환경변수 또는 권한 분리된 외부 properties 파일.
- 모든 배포는 롤백 가능한 형태로 진행(이전 버전 JAR 보관, DB 마이그레이션은 호환 유지 원칙).
- 운영 변경은 변경관리(승인 → 작업 → 검증 → 보고) 기록을 남길 것.
- Docker Compose는 개발용 PostgreSQL에만 사용한다. stage/prod 배포 절차에는 운영용 compose 파일을 만들거나 사용하지 않는다.
