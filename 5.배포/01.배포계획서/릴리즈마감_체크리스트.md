## 3. 배포 전 백업

- `5.배포/05.백업복구절차서/백업정책.md` 기준으로 `pg_dump -Fc` 백업을 수행한다.
- checksum 파일을 생성하고 검증한다.
- 필드 암호화 키 환경변수 보관 위치를 확인한다.

## 4. 태그 기준

- 태그 형식: `v{major}.{minor}.{patch}`
- 태그 전 `RESULT.md`에 최종 검증 결과와 미완/후속 항목을 기록한다.
- 태그 후 운영 배포 산출물의 JAR, 설정 파일, migration 목록을 기록한다.

## 5. 롤백 판단

롤백은 다음 중 하나에 해당할 때 검토한다.

- 애플리케이션 기동 실패
- Flyway migration 실패
- 관리자 로그인 불가
- `/chat` 기본 세션 시작 실패
- 데이터 복호화 실패가 반복 발생

롤백 절차는 직전 JAR/config 재배포와 DB 백업 복구를 분리해서 판단한다. DB down migration은 기본 가정하지 않는다.
