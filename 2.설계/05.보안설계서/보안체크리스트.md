## CSRF 토큰 쿠키 예외 근거

- Spring Security의 쿠키 기반 CSRF 토큰은 서버가 발급한 토큰을 브라우저 JavaScript가 읽고 `X-CSRF-TOKEN` 또는 Spring Security 기본 CSRF 헤더로 되돌려 보내는 패턴을 사용한다.
- 이 헤더 전송을 위해 CSRF 토큰 쿠키만 `HttpOnly=false`로 둔다. 세션 쿠키와 `anonymous_id` 같은 식별 쿠키는 `HttpOnly=true`를 유지한다.
- 예외 쿠키에도 `Secure=true`, `SameSite=Lax`를 적용하고, 토큰 값은 감사 로그, 운영 로그, 오류 응답, 관리자 API 응답에 포함하지 않는다.

## 운영 환경변수

- `CLEVERCHAT_ADMIN_SEED_USERNAME`: 초기 관리자 아이디
- `CLEVERCHAT_ADMIN_SEED_PASSWORD`: 초기 관리자 비밀번호
- `CLEVERCHAT_ADMIN_SEED_DISPLAY_NAME`: 초기 관리자 표시명
- `CLEVERCHAT_OPERATOR_SEED_USERNAME`: 초기 OPERATOR 아이디
- `CLEVERCHAT_OPERATOR_SEED_PASSWORD`: 초기 OPERATOR 임시 비밀번호
- `CLEVERCHAT_OPERATOR_SEED_DISPLAY_NAME`: 초기 OPERATOR 표시명
- `CLEVERCHAT_OPERATOR_SEED_ENABLED`: 운영 기본값 `false`
- `CLEVERCHAT_OPERATOR_SEED_MUST_CHANGE_PASSWORD`: 운영 기본값 `true`
- `CLEVERCHAT_AUTH_MAX_FAILED_ATTEMPTS`: 로그인 실패 잠금 임계값
- `CLEVERCHAT_AUTH_LOCK_MINUTES`: 잠금 시간
- `CLEVERCHAT_CHAT_MATCH_CACHE_TTL_SECONDS`: 매칭 캐시 TTL. 기본값 300
