# M4 검색 화면 목록

> 작성일: 2026-05-11

| 화면 ID | 화면명 | URL | 권한 | 주요 기능 |
|---|---|---|---|---|
| ADM-SCH-001 | 검색 로그 | `/admin/search/logs` | ADMIN/OPERATOR | 검색어, 출처, 기간 필터와 결과 건수/지연 시간 조회 |
| ADM-SCH-002 | PII 차단 검색 | `/admin/search/blocks` | ADMIN/OPERATOR | 차단 시각, PII 유형, 출처 조회. 원문 미노출 |
| ADM-SCH-003 | 인기 검색어 | `/admin/search/popular` | ADMIN/OPERATOR | 일별 인기 검색어, 무결과 수, 재집계 요청 |

## 접근성 기준

- 검색 필터 입력은 `label` 또는 `aria-label`과 연결한다.
- 결과 수와 필터 적용 상태는 텍스트로 제공한다.
- 표 헤더는 `th scope="col"`을 사용한다.
- 재집계/파기 버튼은 처리 대상 날짜 또는 기간을 버튼명이나 `aria-label`에 포함한다.
- 비동기 결과 갱신은 필요한 경우 `aria-live` 영역으로 알린다.
