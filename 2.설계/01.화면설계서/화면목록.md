## 후속 화면 백로그

- `/chat/error`: 별도 오류/만료 안내 화면은 현재 API 상태 메시지와 `/chat` 화면 내 안내로 대체한다.
- 접근성 시각 QA: 명도 대비와 실제 브라우저 수동 검증은 후속 M7 작업으로 둔다.
- Elasticsearch/벡터 검색 운영 화면: PostgreSQL FTS 품질 한계가 확인될 때 추가한다.
- 알림 provider별 전용 화면: webhook/Slack/email 기본형 이후 adapter별 상세 설정이 필요할 때 추가한다.

## 접근성 기본 규칙

- 모든 폼 입력은 `label`, `aria-label`, `aria-describedby` 중 하나와 연결한다.
- 오류 메시지는 `role="alert"`, 저장/조회 결과 메시지는 `role="status"` 또는 `aria-live="polite"`로 유지한다.
- 주요 조작은 native `button`, `a`, `form` 흐름을 우선 사용해 키보드 조작을 보장한다.
- 테이블은 `caption` 또는 `aria-label`, `th scope="col"` 기준을 유지한다.
- 명도 대비는 WCAG AA 4.5:1 이상을 기준으로 하며 실제 시각 QA는 후속 점검 항목으로 관리한다.

## M6 Notification Screen Update

- `/admin/notifications` supports generic webhook, Slack-compatible webhook, and email SMTP channel types.
- The channel form includes primary endpoint env key or email recipient env key, plus optional previous endpoint env key for webhook rotation.
- Provider-specific settings remain follow-up screen work.
