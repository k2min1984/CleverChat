## 접근성 기본 규칙

- 모든 폼 입력은 `label`과 연결한다.
- 인증 오류, 저장 실패 등 즉시 인지해야 하는 메시지는 `role="alert"`을 사용한다.
- 관리자 화면의 버튼은 키보드 포커스만으로 실행 가능해야 한다.
- 명도 대비는 WCAG AA 4.5:1 이상을 기준으로 한다.
- 동적 목록/검색 결과 변경은 필요한 경우 `aria-live` 영역으로 알린다.
- 삭제/게시/활성화 같은 상태 변경은 키보드 접근 가능한 확인 모달 또는 확인 화면을 사용한다.

## M2 결정사항 9절 화면 반영

- `ADM-002`는 `must_change_password=true` 대상 사용자를 강제 유도하는 화면이며, OPERATOR 시드는 비활성 계정으로 생성된 뒤 활성화 절차와 함께 최초 비밀번호 변경 흐름을 검증한다.
- 관리자 M2 화면 권한은 `ADMIN/OPERATOR`를 기준으로 유지하고, ADMIN 전용 기능은 화면 메뉴와 서버 권한에서 별도 분기한다.
- 쿠키 보안 기준은 `SameSite=Lax`, `Secure=true`, `HttpOnly=true`이며, CSRF 토큰 쿠키만 AJAX 헤더 전송을 위해 `HttpOnly=false` 예외를 둔다.
- 프록시 헤더 기준은 `server.forward-headers-strategy=framework`, prod 프로파일 전용 부팅 경고 로그다.
- M4 검색 화면 상세는 `2.설계/01.화면설계서/M4_검색화면목록.md`를 기준으로 한다.
