## 3. `CHAT-001` 챗봇 메인

| 항목 | 명세 |
|---|---|
| URL/권한 | `/chat`, 전체 접근 |
| 진입 경로 | 홈, 관리자 미리보기, 공유 링크 |
| 주요 컴포넌트 | 시나리오 선택 목록, 추천 질문, 최근 이력 진입, 새 대화 시작 버튼 |
| 로딩 | 추천 질문 skeleton 또는 텍스트 로딩 상태. `aria-live="polite"` |
| 에러 | 시나리오 목록 조회 실패 시 재시도 버튼과 오류 문구 |
| 빈 상태 | 활성 시나리오 없음 안내, 관리자 문의 문구 |
| 만료 | 기존 세션 만료 안내 후 새 대화 시작 버튼 |
| 키보드 동선 | 본문 건너뛰기 → 추천 질문 → 시나리오 목록 → 이력 → 새 대화 |
| 모바일 ≤768px | 단일 컬럼, 추천 질문은 세로 버튼 목록, 터치 타깃 44px 이상 |
| 접근성 핵심 | 추천 질문은 `<button>`, 시나리오 상세 이동은 `<a>`, 현재 선택/로딩 상태를 텍스트로 제공 |

`anonymous_id` 쿠키 분실 시:

- 서버는 새 `anonymous_id`를 발급한다.
- 기존 `/chat/history`는 비어 있는 상태로 보인다.
- 사용자가 이전 링크 `/chat/{sessionId}`로 접근하면 본인 검증 실패로 `/chat/error?reason=forbidden` 안내 후 새 대화 시작 버튼을 제공한다.

## 4. `CHAT-002` 진행 중 세션

| 항목 | 명세 |
|---|---|
| URL/권한 | `/chat/{sessionId}`, 본인 세션만 |
| 진입 경로 | `/chat`에서 세션 시작, `/chat/history`에서 이어보기 |
| 주요 컴포넌트 | 메시지 타임라인, 봇/사용자 말풍선, 옵션 버튼 목록, 자유 텍스트 입력, 전송/종료 버튼, 만족도 버튼 |
| 로딩 | 전송 중 입력 비활성화, 진행 상태 텍스트 제공 |
| 에러 | 옵션 충돌, 네트워크 실패, 검증 실패를 입력 영역 인근에 표시 |
| 만료 | 410 응답 시 입력 비활성화, 새 세션 시작 버튼 노출 |
| 빈 상태 | 세션은 있으나 메시지 없음이면 상태 재조회 후 시작 노드 표시 |
| 키보드 동선 | 메시지 영역 → 옵션 버튼 → 자유 입력 label/input → 전송 → 종료 → 피드백 |
| 모바일 ≤768px | 입력 영역 하단 고정 가능. 고정 시 화면 확대/키보드와 겹치지 않게 safe area 적용 |
| 접근성 핵심 | 메시지 영역 `aria-live="polite"`, 시스템 오류 `aria-live="assertive"`, 전송 실패 `role="alert"` |

상태별 표현:

| 상태 | 표현 |
|---|---|
| `ACTIVE` | 입력/옵션 활성화, 남은 시간 문구는 필요 시 보조 텍스트로 제공 |
| `COMPLETED` | 종료 메시지, 만족도 입력 가능, 새 대화 시작 버튼 |
| `ABANDONED` | 사용자가 종료한 대화 안내, 읽기 전용 |
| `EXPIRED` | 만료 안내, 새 세션 시작 버튼, 이전 메시지는 읽기 전용 |

키워드 변경 반영 안내 패턴:

| 메시지 ID | 상황 | 컴포넌트/위치 | 토스트 텍스트 | aria-live 영역 텍스트 | 접근성/동작 기준 |
|---|---|---|---|---|---|
| KW-MSG-01 | 운영자가 키워드/유사어를 저장했고 기존 매칭 캐시가 남아 있을 수 있는 경우 | 관리자 저장 완료 토스트와 저장 버튼 인근 상태 영역 | 키워드 변경은 저장되었습니다. 챗봇 사용자 화면에는 최대 300초 후 반영될 수 있습니다. | 키워드 변경 저장 완료. 챗봇 사용자 화면 반영은 최대 300초 지연될 수 있습니다. | 토스트는 `role="status"`, 상태 영역은 `aria-live="polite"`를 사용한다. 토스트는 5초 뒤 자동 사라짐, 상태 영역은 다음 저장 시까지 유지한다. |
| KW-MSG-02 | 사용자가 자유 텍스트를 입력했으나 최근 변경 키워드와 매칭되지 않은 경우 | 입력 영역 인근 보조 안내 또는 실패 카드 하단 | 최근 변경된 키워드는 최대 300초 후 반영될 수 있습니다. 잠시 후 다시 시도해 주세요. | 최근 변경된 키워드가 아직 반영되지 않았을 수 있습니다. 최대 300초 후 다시 시도해 주세요. | 사용자 화면에서는 토스트보다 입력 영역 인근 안내를 우선한다. 실패 카드 하단 안내는 `aria-describedby`로 입력 또는 실패 카드와 연결한다. |
| KW-MSG-03 | 캐시 무효화 성공 로그가 확인되어 즉시 반영 가능한 경우 | 관리자 저장 완료 토스트와 화면 상단 상태 영역 | 키워드 변경이 즉시 반영되었습니다. | 키워드 변경 저장 완료. 챗봇 사용자 화면에 즉시 반영되었습니다. | 토스트와 상태 영역 모두 `aria-live="polite"` 기준이다. 성공 안내는 오류 alert로 처리하지 않는다. |

운영자 키워드 화면 컴포넌트 고정 스펙:

- 저장 성공 토스트는 `role="status"`와 `aria-live="polite"`를 사용하고, 포커스를 강제로 이동하지 않는다.
- 같은 안내 문구를 보존해야 하는 경우 저장 버튼 인근 또는 화면 상단 상태 영역에 `aria-live="polite"`로 노출한다.
- 토스트 자동 사라짐 기준은 5초이며, 마우스 hover 또는 키보드 포커스가 토스트 내부에 있을 때는 자동 닫힘을 일시 중지한다.
- 모바일 768px 이하에서는 토스트가 입력 필드, 저장 버튼, 하단 고정 액션을 가리지 않도록 상단 고정 또는 상태 영역 우선 노출을 사용한다.
- `M3_운영자화면목록.md`는 본 표의 `KW-MSG-01`~`KW-MSG-03` 텍스트와 role/aria-live 기준을 동일하게 복제하며, 변경 시 양쪽 문서를 함께 갱신한다.

## 5. `CHAT-003` 대화 이력

| 항목 | 명세 |
|---|---|
| URL/권한 | `/chat/history`, `anonymous_id` 본인 |
| 호출 API | `GET /chat/api/history` (M3 챗봇 런타임 API §3.7) |
| 진입 경로 | `/chat` 최근 이력 링크 |
| 주요 컴포넌트 | 상태 필터, 기간 필터(`from`/`to`), 이력 목록, 상태 배지, 시나리오명, 메시지 수, 마지막 활동 시각, 마지막 봇 메시지 요약, 페이지네이션 |
| 표시 필드 | `state`, `scenarioTitle`, `messageCount`, `startedAt`, `lastActivityAt`, `lastBotMessageSummary`(80자 이하 마스킹 요약). 응답에 `anonymous_id`/IP/UA 원문이 포함되지 않으므로 화면에도 노출하지 않는다. |
| 정렬 | `lastActivityAt DESC, sessionId DESC` 고정. 사용자 정렬 변경 옵션은 M3 미지원 |
| 페이지 크기 | API 기본 `size=20`, 최대 `size=50`. 화면 페이지네이션은 기본 20건이며 50건 selector를 함께 제공한다. |
| 기간 필터 | `from`/`to` 입력 가능. 기본은 최근 90일(서버 기본값). 사용자 입력 시 `from`-`to` 간격은 90일 이내로 제한하고 초과 시 클라이언트에서 사전 검증해 `400 INVALID_REQUEST`를 받지 않도록 안내한다. `to`가 현재 시각 이후이면 서버가 현재 시각으로 보정함을 안내 텍스트로 노출한다. |
| 상태 필터 | `state` allow-list = `ACTIVE`, `COMPLETED`, `ABANDONED`, `EXPIRED`. 기본은 전체. `EXPIRED`도 목록에 포함된다. |
| 로딩 | 목록 영역 로딩 텍스트 |
| 에러 | 조회 실패 재시도 버튼. 기간 검증 오류 시 입력 인근 안내 |
| 빈 상태 | "최근 90일 대화 이력이 없습니다." `anonymous_id` 쿠키가 없으면 서버는 빈 페이지를 반환하고 새 식별자를 강제 발급하지 않으며 동일 빈 상태 문구를 노출한다. |
| 만료 | 만료(`EXPIRED`) 세션은 상태 배지와 읽기 전용 상세 링크. 90일 보존 범위를 초과한 세션은 응답에서 제외된다. |
| 키보드 동선 | 상태 필터 → 기간 필터 → 검색 → 목록 링크 → 페이지네이션 |
| 모바일 ≤768px | 카드형 목록. 상태/시간/시나리오명이 줄바꿈되어도 겹치지 않음 |
| 접근성 핵심 | 결과 수 텍스트 제공, 페이지네이션 현재 페이지 표시. `lastBotMessageSummary`가 ellipsis로 잘릴 경우 `aria-label`로 80자 마스킹 요약 전체를 제공한다. |

## 6. `CHAT-004` 챗봇 오류

| 항목 | 명세 |

| 진입 경로 | 만료, 본인 검증 실패, 시스템 오류 redirect |
| 주요 컴포넌트 | 오류 제목, 원인별 안내, 새 대화 시작, 홈 이동 |
| 로딩 | 없음 |
| 에러 | 오류 화면 자체 실패 시 공통 오류 템플릿 |
| 빈 상태 | 해당 없음 |
| 키보드 동선 | 오류 안내 → 새 대화 시작 → 홈 |
| 모바일 ≤768px | 버튼 세로 배치 |
| 접근성 핵심 | 주요 오류 문구 `role="alert"`, 원인별 조치 텍스트 제공 |

원인별 문구 기준:

| reason | 사용자 안내 |
|---|---|
| `expired` | 대화가 30분 이상 없어 만료되었음을 안내 |
| `forbidden` | 현재 브라우저에서 확인할 수 없는 대화임을 안내 |
| `not_found` | 존재하지 않거나 삭제된 대화임을 안내 |
| `system` | 일시 오류와 재시도 안내 |

## 7. 관리자 화면 목록

### 7.1 `ADM-CHAT-001` 세션 목록

- URL/권한: `/admin/chat/sessions`, ADMIN/OPERATOR
- 진입 경로: 관리자 메뉴 "챗봇 운영"
- 주요 컴포넌트: 상태/시나리오/기간 필터, 세션 테이블, 페이지네이션
- 상태별 표현: 결과 없음, 로딩, API 오류, 기간 필터 오류
- 키보드 동선: 필터 → 검색 → 테이블 상세 링크 → 페이지네이션
- 모바일: 관리자 화면은 기본 데스크톱 우선이나 768px 이하에서 테이블은 가로 스크롤 또는 요약 카드
- 접근성: 테이블 `th scope`, 필터 label, 결과 수 텍스트

### 7.2 `ADM-CHAT-002` 세션 상세

- URL/권한: `/admin/chat/sessions/{id}`, ADMIN/OPERATOR
- 주요 컴포넌트: 세션 메타, 상태 전이 타임라인, 메시지 트레이스, 실패/피드백 연결
- 개인정보: `anonymous_id`, IP, UA 원문 미노출. 해시 일부 또는 내부 ID만 표시
- 키보드 동선: 뒤로가기 → 메타 → 메시지 목록 → 실패/피드백 링크
- 접근성: 메시지 방향과 seq를 텍스트로 제공

### 7.3 `ADM-CHAT-003` 실패 큐

- URL/권한: `/admin/chat/failures`, ADMIN/OPERATOR
- 주요 컴포넌트: reviewed 필터, reason 필터, 실패 목록, 처리 버튼, 검토 코멘트 입력
- 상태별 표현: 미처리 없음, 처리 완료, 처리 실패
- 키보드 동선: 필터 → 목록 → 처리 버튼 → 코멘트 → 저장
- 접근성: 처리 결과 `role="status"`, 코멘트 label 연결

### 7.4 `ADM-CHAT-004` 피드백 목록

- URL/권한: `/admin/chat/feedback`, ADMIN/OPERATOR
- 주요 컴포넌트: rating 필터, 기간 필터, 코멘트 목록, 세션 상세 링크
- 상태별 표현: 결과 없음, 코멘트 없음, 로딩 실패
- 키보드 동선: 필터 → 테이블 → 상세 링크
- 접근성: `UP`/`DOWN`은 아이콘만 쓰지 않고 텍스트를 함께 제공

### 7.5 `ADM-CHAT-005` 추천 질문 관리

- URL/권한: `/admin/chat/recommendations`, ADMIN/OPERATOR
- 진입 경로: 관리자 메뉴 "챗봇 운영" → "추천 질문 관리"
- 주요 컴포넌트: 추천 질문 목록, 시나리오 선택, label 입력, priority 입력, enabled 토글, 등록/수정/삭제 버튼
- 입력 기준: label 1~200자, priority 0~9999, scenario는 active 시나리오 우선 선택
- 상태별 표현: 결과 없음, 저장 완료, 삭제 완료, 검증 오류, 시나리오 비활성 경고
- 동작 기준: `enabled=false` 토글 저장 즉시 `GET /chat/api/recommendations` 응답에서 제외한다.
- 키보드 동선: 필터/검색 → 목록 행 편집 → 입력 필드 → enabled 토글 → 저장/삭제 → 페이지네이션
- 접근성: 토글은 checkbox 또는 switch role로 상태를 제공하고, 저장 결과는 `role="status"`와 `aria-live="polite"`로 알린다.

## 8. 화면/API 정합

| 화면 | 호출 API |
|---|---|
| `/chat` | `GET /chat/api/scenarios`, `GET /chat/api/recommendations`, `POST /chat/api/sessions` |
| `/chat/{sessionId}` | `GET /chat/api/sessions/{id}`, `POST /select-option`, `POST /free-text`, `GET /history`, `POST /end`, `POST /feedback` |
| `/chat/history` | `GET /chat/api/history` |
| `/admin/chat/sessions` | `GET /admin/api/chat/sessions` |
| `/admin/chat/sessions/{id}` | `GET /admin/api/chat/sessions/{id}` |
| `/admin/chat/failures` | `GET /admin/api/chat/failures`, `POST /review` |
| `/admin/chat/feedback` | `GET /admin/api/chat/feedback` |
| `/admin/chat/recommendations` | `GET/POST /admin/api/chat/recommendations`, `GET/PUT/DELETE /admin/api/chat/recommendations/{id}` |

이력 목록 API는 `GET /chat/api/history`로 확정한다. 본 문서의 `/chat/history` 화면에는 90일 내 본인 이력만 노출한다. 화면 필터와 표시 필드는 API §3.7의 `size` 최대 50, `from`/`to` 최대 90일 범위, 상태 allow-list, `lastBotMessageSummary` 80자 마스킹 요약 기준을 따른다.
