## 1. 공통 점검

- [ ] 키보드만으로 모든 시나리오 진행이 가능하다. `Tab`, `Shift+Tab`, `Enter`, `Space` 기준.
- [ ] 메시지 영역은 `aria-live="polite"`로 새 봇 메시지를 알린다.
- [ ] 시스템 오류와 만료 안내는 `aria-live="assertive"` 또는 `role="alert"`로 제공한다.
- [ ] 모든 입력에는 명시적 `<label>`이 있고 도움말은 `aria-describedby`로 연결한다.
- [ ] 버튼은 `<button>`, 페이지 이동은 `<a>`를 사용해 의미를 분리한다.
- [ ] 일반 텍스트와 배경 명도 대비는 4.5:1 이상이다.
- [ ] 사용자/봇 메시지 색상 구분은 텍스트 레이블 또는 보조 아이콘 설명과 함께 제공한다.
- [ ] 포커스 표시가 명확하며 `outline`을 제거하지 않는다.
- [ ] 스크린리더가 송신/수신 방향을 알 수 있다. 예: "사용자 메시지", "챗봇 답변".
- [ ] 종료/만료 안내는 색상만이 아니라 텍스트로 제공한다.
- [ ] 이미지와 아이콘에는 `alt` 또는 `aria-label`을 제공한다. 장식 아이콘은 `aria-hidden="true"`.
- [ ] 오류 메시지는 `role="alert"`로 즉시 전달한다.
- [ ] 모바일 터치 타깃은 최소 44x44px이다.
- [ ] 입력 중 비활성화 상태는 `disabled` 또는 `aria-disabled`와 텍스트 상태로 알린다.
- [ ] 결과 없음, 검색 실패, fallback 상태를 텍스트로 제공한다.

## 2. 화면별 점검

| 화면 | 체크 항목 |
|---|---|
| `/chat` | 추천 질문 버튼에 목적이 드러나는 accessible name을 제공한다. |
| `/chat` | 시나리오 목록 로딩/빈 상태를 텍스트와 live region으로 제공한다. |
| `/chat/{sessionId}` | 메시지 타임라인의 DOM 순서가 실제 대화 순서와 같다. |
| `/chat/{sessionId}` | 새 메시지 추가 시 포커스를 강제로 빼앗지 않는다. 단, 오류는 alert로 알린다. |
| `/chat/{sessionId}` | 옵션 버튼은 키보드로 순회 가능하고 선택 후 진행 상태를 알린다. |
| `/chat/{sessionId}` | 자유 텍스트 입력은 label, 글자 수 제한 안내, 오류 설명이 연결되어 있다. |
| `/chat/{sessionId}` | 만족도 `UP`/`DOWN` 버튼은 아이콘만 쓰지 않고 `aria-label`로 의미를 제공한다. |
| `/chat/history` | 결과 수, 현재 페이지, 페이지 이동 버튼 상태를 제공한다. |
| `/chat/error` | 오류 원인과 다음 조치가 텍스트로 제공된다. |
| `/admin/chat/*` | 데이터 테이블은 `th scope="col"`과 행 액션 이름을 제공한다. |

## 3. 키보드 동선

### `/chat`

1. 본문 건너뛰기 링크
2. 추천 질문 버튼 목록
3. 시나리오 목록
4. 대화 이력 링크
5. 새 대화 시작 또는 홈 이동

### `/chat/{sessionId}`

1. 메시지 영역 제목
2. 현재 노드 옵션 버튼
3. 자유 텍스트 입력
4. 전송 버튼
5. 종료 버튼
6. 만족도 버튼
7. 새 대화 시작 링크

### `/chat/history`

1. 기간/상태 필터
2. 이력 목록 링크
3. 페이지네이션
4. `/chat` 돌아가기

## 4. 컴포넌트별 기준

| 컴포넌트 | 기준 |
|---|---|
| 메시지 말풍선 | 방향, 시간, 본문을 텍스트로 인지 가능해야 한다. |
| 옵션 버튼 | label은 1~80자 권장. 긴 문구는 줄바꿈되어도 버튼 밖으로 넘치지 않는다. |
| 자유 입력 | 500자 제한 안내와 남은 글자 수는 보조 텍스트로 제공한다. |
| 피드백 | `좋아요`, `도움이 안 됨` 의미가 스크린리더에 전달되어야 한다. |
| fallback 카드 | 카드 전체를 버튼처럼 만들지 않는다. 제목 링크와 선택 버튼의 의미를 분리한다. |
| 오류 배너 | 발생 위치 인근에 표시하고 `role="alert"`를 사용한다. |
| 관리자 저장 토스트 | 성공/지연/즉시 반영 안내는 `role="status"`와 `aria-live="polite"`로 제공하고 5초 뒤 자동 사라짐을 허용한다. |
| 관리자 상태 영역 | 토스트와 같은 안내 문구를 보존해야 할 때는 화면 상단 또는 저장 버튼 인근의 `aria-live="polite"` 영역에 같은 메시지를 제공한다. |

## 5. 수동 확인 방법

- [ ] 마우스를 사용하지 않고 `/chat`에서 세션 시작 후 종료까지 진행한다.
- [ ] 자유 텍스트 입력 오류, 만료, fallback 상태가 스크린리더 또는 브라우저 접근성 트리에서 인지되는지 확인한다.
- [ ] 크롬/엣지 개발자 도구 또는 검사 도구로 명도 대비 4.5:1 이상을 확인한다.
- [ ] 360px, 768px, 1280px 폭에서 버튼 텍스트와 입력 영역이 겹치지 않는지 확인한다.
- [ ] `prefers-reduced-motion` 사용자가 불필요한 애니메이션 없이 사용할 수 있는지 확인한다.
