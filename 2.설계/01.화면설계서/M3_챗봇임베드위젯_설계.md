# M3 챗봇 임베드 위젯 설계

## 1차 기준

- v1 embed baseline은 launcher-only 방식이다. 외부 페이지는 버튼이나 링크를 제공하고, 사용자는 `/chat`을 새 창 또는 새 탭으로 연다.
- `/chat` 직접 iframe embedding은 현재 허용하지 않는다.
- 외부 도메인에서 `/chat/api/**`를 직접 호출하는 JS widget runtime은 현재 허용하지 않는다.
- 기존 보안 기준인 `frame-ancestors 'none'`, `X-Frame-Options: DENY`, same-origin API, CSRF 정책, `ApiResponse` envelope를 유지한다.

## 운영 샘플

- 샘플 파일: `3.개발/cleverchat/deploy/embed/cleverchat-embed-sample.html`
- 샘플은 launcher button과 `/chat` 새 창 이동만 포함한다.
- 샘플에는 iframe, `/chat/api/**` 호출, embed token, secret, authorization header, 개인정보 query string 예시를 넣지 않는다.

## 보안 경계

- CSP: `frame-ancestors 'none'`을 유지해 외부 iframe 삽입을 차단한다.
- CORS: 외부 origin 허용을 추가하지 않는다.
- Cookie SameSite/Secure: 익명 사용자 식별 쿠키는 애플리케이션 소유 범위에서만 사용한다. 외부 iframe 허용 전에는 SameSite/Secure 영향 검토가 필요하다.
- CSRF: `/chat/api/**` 호출은 기존 CSRF와 same-origin 전제를 유지한다.
- 접근성: launcher button은 keyboard focus, visible focus, accessible name을 제공해야 한다.

## 후속 허용 조건

- iframe allowlist를 도입하려면 허용 도메인, `frame-ancestors` 정책, `X-Frame-Options` 제거 여부, cookie SameSite/Secure 기준을 먼저 확정한다.
- public JS widget runtime을 도입하려면 CORS allowlist, CSRF 전략, embed token, abuse/rate limit, API envelope 호환성을 먼저 확정한다.
- 관리자 UI에서 허용 도메인과 embed 설정을 관리하는 기능은 별도 작업으로 분리한다.
