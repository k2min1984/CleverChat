## 1. 작성 기준과 자료 범위

기존 [KEPCO 시나리오 생성 소스](../../3.개발/cleverchat/tools/KepcoScenarioSeeder.java)의 대메뉴·하위 메뉴 구성 방식을 참고하여, DB에 저장된 크롤링 자료로 답변을 구성하고, 본문 부족 항목과 일부 제도 안내는 공식 홈페이지를 추가 조회하여 보완했습니다. 변경 전 활성 v1을 복사해 v2를 만들고 검증 후 활성 버전을 교체했습니다.

| 항목 | 적용 기준 |
|---|---|
| 자료 범위 | 한전 홈페이지 크롤링 대상 1번의 수집 성공 문서 4,358건 중 안내에 적합한 자료를 선별했습니다. |
| 시나리오 구분 | KEPCO, 사업분야, 정보공개, ESG경영, 홍보센터, 고객소통의 6개 대메뉴로 나눴습니다. |
| 대화 구성 | 대메뉴 → 하위 메뉴 선택 → 해당 항목의 답변 → 원문 링크 순서입니다. |
| 답변 작성 | 답변 첫 문장에서 질문에 직접 답하고, 핵심 내용·사례·수치·조건·처리 절차 중 해당 항목에 필요한 내용을 설명합니다. 단순한 페이지 소개나 원문 확인 요청만으로 끝내지 않습니다. |
| 게시물 처리 | 확인된 수치와 조건은 답변에 직접 제시하고 연도·단위·대상을 붙입니다. 목표와 실적, 예산과 결산, 개정 예고와 시행 규정을 구분합니다. |
| 본문 부족 | 기존 원문 연결 중심의 12개 항목은 공식 페이지 본문으로 보완했습니다. 첨부파일까지 읽지 못한 자료는 확인된 게시정보·자료 구분을 설명하고 미확인 범위를 명시합니다. |
| 출처 추적 | 기존 수집 문서 번호·URL·시각·해시를 보존하고, 추가 조회를 사용한 18개 답변에는 공식 페이지 URL·조회시각·본문 해시를 별도로 기록했습니다. 추가 조회 페이지는 중복 제외 17개입니다. |
| 검색 연결 | 주제·메뉴명 키워드 148개를 등록했습니다. 자유문장 매칭의 품질 검증은 이 문서의 미리보기 검증과 별도입니다. |

추가 조회일은 2026-09-22입니다. 전체 4,358개 원문과 모든 첨부파일을 재수집한 것은 아닙니다. 답변의 수치·연도는 인용한 자료 기준이며 자동 갱신되지 않습니다. 원문의 상충 표기나 기준 시점이 불명확한 수치는 임의로 확정하지 않았습니다.

## 3. 공통 이동 규칙

| 버튼 | 연결 |
|---|---|
| 주제·하위 메뉴 버튼 | 선택한 항목의 질문 또는 답변 노드로 이동합니다. |
| 이전 | 시스템이 기록한 실제 방문 경로의 직전 화면으로 돌아갑니다. 검색에서 답변을 열었다면 검색 목록으로, 메뉴에서 들어왔다면 앞서 방문한 상담 단계로 복귀합니다. |
| 안내 종료 | 해당 시나리오의 END 노드로 이동합니다. END 노드에는 시나리오 선택지가 없습니다. |
| 원문 보기 | 답변의 출처 페이지를 외부 링크로 엽니다. |

시나리오에는 **내용 선택지와 안내 종료만 등록**합니다. `상위 메뉴`, `처음으로`, 고정 목적지의 `이전` 선택지를 새로 만들지 않습니다. 시스템의 `이전` 버튼은 돌아갈 이력이 있을 때만 표시되며, 첫 화면에는 없습니다. 일반 답변의 버튼 순서는 **이전 · 안내 종료**입니다.

아래 선택지 표는 DB에 등록된 내용 분기와 종료 연결을 기록합니다. `이전`은 시스템 기능이므로 표의 고정 노드 연결에 포함하지 않습니다. 기존 v1·v2 데이터는 보관하되, 공개 챗봇은 이전 대화에서도 예전 이동 선택지를 숨깁니다.

## 6. 확인 결과와 검증 범위

### v3 이동 방식 정리

- 활성 시나리오 6개를 v3로 교체했습니다. 노드 125개, 답변 90개, 출처 링크 및 내용 분기는 그대로 유지했습니다.
- 상위 메뉴·처음으로 193개를 제거해 등록 선택지가 425개에서 232개로 줄었습니다. 모든 노드가 시작점에서 도달 가능하며, 종료 연결도 유지됩니다.
- 관리자 API로 저장 후 그래프를 다시 읽어 정리한 내용과 비교했습니다. 기존 v2 그래프도 원본과 동일함을 확인했습니다.
- 공개 화면은 예전 버전의 이동 선택지까지 숨기고 실제 방문 경로를 따르는 시스템 이전 버튼을 제공합니다.
- 브라우저에서 v2·v3 각각 6개 시나리오의 답변 버튼이 `이전 · 안내 종료`로 표시되는지 확인했습니다. 이전 단계 복원, 종료 처리, 전기요금 검색으로 연 답변에서 검색 목록으로 복귀까지 확인했으며 JavaScript 오류는 없었습니다.

### v2 본문 보완 당시 검증 기록

아래는 2026-09-22의 본문 보완 및 당시 이동 구성에 대한 기록입니다. 현재 이동 방식은 위 v3 규칙을 따릅니다.

- 관리자 API로 시나리오·그래프·키워드를 등록한 뒤 저장된 그래프를 다시 읽어 작성 내용과 비교했습니다.
- 6개 시나리오의 125개 노드를 관리자 미리보기로 순회하여 시작 노드에서 모든 노드에 도달하는지 확인했습니다.
- 미리보기에서 답변별 원문 링크 90개와 선택지 연결 425개의 표시·연결을 확인했습니다. 원문 사이트의 링크를 모두 직접 방문한 검증은 아닙니다.
- 관리자 편집 화면에서 6개 시나리오의 노드가 모두 로드되는지 확인했습니다.
- 고객소통 미리보기에서 온라인·방문 민원 → 온라인 고객상담 → 상위 메뉴 → 처음으로 → 안내 종료를 실제 버튼으로 확인했습니다.
- 활성 버전 교체 후 6개 시나리오의 v2 그래프를 다시 읽어 작성 내용과 비교했습니다. 기존 v1 그래프 보존도 확인했습니다.
- ESG경영 → 한전의 ESG → 핵심성과를 실제 미리보기 버튼으로 이동하여 상세 답변을 확인했습니다.
- 공개 챗봇의 새 상담에서 ESG경영 → 한전의 ESG → 핵심성과를 실제 버튼으로 진행했습니다. 활성 버전 ID 10(v2)이 선택되고, 반환된 답변이 보완한 본문과 일치함을 확인했습니다.
- 복귀 버튼 중복 정리 후 중첩 답변은 `상위 메뉴·처음으로·안내 종료`, 시작 질문 바로 아래 답변은 `처음으로·안내 종료`만 표시됨을 확인했습니다. 상위 메뉴·처음으로·종료 동작과 검색 문서에서 `이전`을 눌러 기존 검색 결과 7개를 복원하는 동작도 확인했습니다.
