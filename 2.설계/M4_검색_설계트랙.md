# M4 검색 설계 트랙

> 작성일: 2026-05-13
> 목적: M4 검색 관련 화면/DB/API/보안/운영/작업지시/테스트 산출물을 하나의 설계 트랙으로 묶어 추적한다.

## 1. 트랙 범위

M4 검색은 M3 자유 텍스트 fallback을 PostgreSQL FTS 기반 검색으로 연결하고, 관리자 운영 화면에서 검색 로그, PII 차단 로그, 인기 검색어 집계를 조회/운영하는 범위다.

| 영역 | 기준 |
|---|---|
| 검색 대상 | 시나리오 제목/설명, 노드 본문, 키워드, 유사어 |
| 검색 엔진 | PostgreSQL FTS `simple` configuration + `pg_trgm` + `unaccent` |
| 검색어 길이 | trim 후 1~200자 |
| PII 기준 | 고위험 PII 차단, 원문 검색어 미저장 |
| 로그 보존 | `search_log`, `search_block_log` 90일 |
| 관리자 화면 | 검색 로그, PII 차단 검색, 인기 검색어 |
| 구현 대상 | Flyway `V5__search_baseline.sql`, M4 검색 서비스/API/관리자 화면 |

## 3. 커밋 경계

M4 검색 설계 트랙은 인증 전환(Security -> Interceptor) 정정, Docker 운영 경계, M3 매칭 캐시 보완과 섞지 않는다.

| 제외 트랙 | 제외 기준 |
|---|---|
| 인증 전환 정정 | `.gitignore`, `3.개발/cleverchat/README.md`, `3.개발/cleverchat/docs/*8소스*`, 인증 서비스 Java 변경 |
| Docker 운영 경계 | `2.설계/06.운영메모/M1_운영메모.md`, `5.배포/README.md` |
| M3 매칭 캐시 | `ScenarioKeywordService.java` |
| 기타 변경 | `mvnw.cmd`, `9.참고/기능요청.md` 등 M4 검색 설계와 직접 관련 없는 변경 |
