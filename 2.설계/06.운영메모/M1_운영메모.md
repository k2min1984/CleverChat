## 초기 관리자 생성

애플리케이션 최초 부팅 전에 다음 환경변수를 주입한다.

```bash
export CLEVERCHAT_ADMIN_SEED_USERNAME=admin
export CLEVERCHAT_ADMIN_SEED_PASSWORD='change-me'
export CLEVERCHAT_ADMIN_SEED_DISPLAY_NAME='시스템 관리자'
```

동일 username이 이미 있으면 시더는 아무 작업도 하지 않는다. 초기 생성 후에는 운영 절차에 따라 비밀번호를 변경하고, 환경변수는 제거하거나 비워도 된다.

## 로컬 검증

1. PostgreSQL 개발 컨테이너를 실행한다.
2. 위 환경변수를 지정한 뒤 애플리케이션을 실행한다.
3. `/login`에서 로그인 후 `/admin` 진입 여부를 확인한다.
4. 실패 로그는 `login_log`, 세션은 `SPRING_SESSION`, 관리자 작업 감사는 `audit_log`에서 확인한다.

## 남은 운영 과제

- 관리자 비밀번호 변경 화면
- 잠금 해제/계정 비활성화 관리 화면
- 감사 로그 조회 화면
- 운영 로그 보존 기간 및 백업 정책
