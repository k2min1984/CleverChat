# 공통 응답 및 에러 코드

> 작성일: 2026-05-08

## 1. REST 응답 형식

```json
{
  "success": true,
  "data": {},
  "error": null,
  "timestamp": "2026-05-08T10:00:00+09:00"
}
```

실패 응답:

```json
{
  "success": false,
  "data": null,
  "error": {
    "code": "SCENARIO_NOT_FOUND",
    "message": "시나리오를 찾을 수 없습니다.",
    "fieldErrors": []
  },
  "timestamp": "2026-05-08T10:00:00+09:00"
}
```

## 2. HTTP 상태 매핑

| 상태 | 사용 기준 |
|---|---|
| 200 | 조회/수정/삭제 성공 |
| 201 | 생성 성공 |
| 400 | 입력값 검증 실패, 업무 규칙 위반 |
| 401 | 인증 필요 |
| 403 | 권한 없음 |
| 404 | 대상 없음 |
| 410 | 만료되어 더 이상 사용할 수 없음 |
| 409 | 중복/상태 충돌 |
| 429 | 요청량 제한 초과 |
| 500 | 예상하지 못한 서버 오류 |

## 3. 에러 코드

| 코드 | HTTP | 설명 |
|---|---:|---|
| `VALIDATION_FAILED` | 400 | Bean Validation 실패 |
| `INVALID_REQUEST` | 400 | 요청 형식 오류 |
| `UNAUTHORIZED` | 401 | 인증 필요 |
| `FORBIDDEN` | 403 | 권한 부족 |
| `RESOURCE_NOT_FOUND` | 404 | 일반 리소스 없음 |
| `DUPLICATE_VALUE` | 409 | 고유값 중복 |
| `STATE_CONFLICT` | 409 | 현재 상태에서 처리 불가 |
| `RATE_LIMIT_EXCEEDED` | 429 | 요청량 제한 초과 |
| `SCENARIO_NOT_FOUND` | 404 | 시나리오 없음 |
| `SCENARIO_VERSION_NOT_FOUND` | 404 | 시나리오 버전 없음 |
| `SCENARIO_NODE_NOT_FOUND` | 404 | 노드 없음 |
| `SCENARIO_ACTIVE_VERSION_REQUIRED` | 400 | 활성화할 게시 버전 없음 |
| `SCENARIO_INVALID_NODE_GRAPH` | 400 | 시작 노드/옵션 연결 오류 |
| `CHAT_SESSION_NOT_FOUND` | 404 | 챗봇 세션 없음 |
| `CHAT_SESSION_EXPIRED` | 410 | 챗봇 세션 만료 |
| `CHAT_SESSION_FORBIDDEN` | 403 | 본인 챗봇 세션 아님 |
| `CHAT_INVALID_OPTION` | 409 | 현재 노드에서 선택할 수 없는 옵션 |
| `CHAT_NODE_TERMINAL` | 409 | 종료 노드에서 추가 진행 요청 |
| `CHAT_FEEDBACK_DUPLICATE` | 409 | 이미 등록된 챗봇 피드백 |
| `CHAT_NO_MATCH` | 404 | 자유 텍스트 매칭 실패 |
| `CHAT_PII_BLOCKED` | 400 | 저장할 수 없는 개인정보 패턴 탐지 |
| `SEARCH_QUERY_EMPTY` | 400 | 검색어가 비어 있음 |
| `SEARCH_QUERY_TOO_LONG` | 400 | 검색어 최대 길이 초과 |
| `SEARCH_PII_BLOCKED` | 400 | 검색어에서 저장할 수 없는 개인정보 패턴 탐지 |
| `SEARCH_RESULT_EMPTY` | 404 | 검색 결과 없음 |
| `INTERNAL_ERROR` | 500 | 서버 오류 |

## 4. 구현 기준

- 화면 Form 요청은 PRG 패턴을 우선 사용한다.
- REST API는 위 공통 응답 형식을 사용한다.
- 예외 메시지는 민감정보, SQL, stack trace를 포함하지 않는다.
- 필드 오류는 `field`, `message` 형태로 반환한다.
- 검색어 PII 차단 응답은 원문 검색어를 되돌려주지 않는다.
