# 인덱스 설계

> 작성일: 2026-05-08

## 1. M1 기존 영역

| 테이블 | 인덱스 | 목적 |
|---|---|---|
| `users` | `uk_users_username` | 로그인 사용자 조회 |
| `roles` | `uk_roles_code` | 권한 코드 조회 |
| `login_log` | `(username, created_at desc)` | 계정별 로그인 이력 |
| `audit_log` | `(target_type, target_id, created_at desc)` | 대상별 감사 추적 |
| `audit_log` | `(actor, created_at desc)` | 관리자별 작업 조회 |

## 2. M2 시나리오

| 테이블 | 인덱스 | 목적 |
|---|---|---|
| `scenario_category` | `(parent_id, sort_order)` | 카테고리 트리 정렬 |
| `scenario` | `(status, updated_at desc)` | 상태별 목록 |
| `scenario` | `(category_id, status, updated_at desc)` | 카테고리 필터 |
| `scenario_version` | unique `(scenario_id, version_no)` | 버전 중복 방지 |
| `scenario_version` | `(scenario_id, status, created_at desc)` | 버전 목록 |
| `scenario_node` | unique `(version_id, node_key)` | 노드 키 중복 방지 |
| `scenario_node` | `(version_id, sort_order)` | 버전별 노드 조회 |
| `scenario_node_option` | `(node_id, sort_order)` | 버튼 옵션 정렬 |
| `scenario_keyword` | `(scenario_id, enabled)` | 시나리오별 키워드 |
| `scenario_keyword` | `(keyword)` | 정확 키워드 검색 |
| `scenario_synonym` | `(keyword_id, enabled)` | 유사어 목록 |
| `scenario_synonym` | `(synonym)` | 정확 유사어 검색 |

## 3. M4 검색

PostgreSQL 확장 적용은 M4 설계에서 확정한다.

```sql
CREATE EXTENSION IF NOT EXISTS pg_trgm;
CREATE EXTENSION IF NOT EXISTS unaccent;
```

| 대상 | 인덱스 | 목적 |
|---|---|---|
| `scenario.search_tsv` | GIN FTS | 제목/설명 검색 |
| `scenario.title` | GIN trigram | 제목 부분 일치 |
| `scenario_node.search_tsv` | GIN FTS | 노드 본문 검색 |
| `scenario_node.content` | GIN trigram | 본문 부분 일치 |
| `scenario_keyword.keyword` | GIN trigram | 키워드 오타/부분 일치 |
| `scenario_synonym.synonym` | GIN trigram | 유사어 오타/부분 일치 |
| `search_log` | `(created_at desc)` | 로그 최신순 조회/파기 |
| `search_log` | `(normalized_query, created_at desc)` | 인기 검색어 집계 |
| `search_block_log` | `(created_at desc)` | 차단 로그 최신순 조회/파기 |
| `popular_query_daily` | `(stat_date desc, search_count desc)` | 일별 인기 검색어 조회 |

## 4. M3 챗봇 런타임

| 테이블 | 인덱스 | 목적 |
|---|---|---|
| `chat_session` | `(anonymous_id, started_at desc)` | 본인 대화 이력 조회 |
| `chat_session` | `(state, expires_at)` | 만료 배치 대상 조회 |
| `chat_message` | unique `(session_id, seq)` | 세션 내 메시지 순서와 seq 충돌 방지 |
| `chat_failure` | `(reviewed, created_at desc)` | 미처리 실패 큐 조회 |
| `chat_feedback` | `(rating, created_at desc)` | 만족도 목록과 통계 |
| `chat_recommendation` | `(enabled, priority, id)` | 추천 질문 노출 |

## 5. 운영 기준

- 신규 목록 API는 인덱스 설계를 먼저 확인한다.
- `%keyword%` LIKE는 M4 전까지 관리자 소량 검색에만 제한한다.
- 운영에서 1초 이상 반복되는 쿼리는 실행계획을 확인하고 인덱스를 조정한다.
