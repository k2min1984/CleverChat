## 3. 우선 보완 범위

M2 시나리오 도메인 구현에 바로 진입할 수 있도록 다음 산출물을 우선 작성한다.

| 우선 | 산출물 | 목적 |
|---|---|---|
| 1 | 아키텍처 기본 문서 | 모듈 경계와 비기능 기준 확정 |
| 2 | M2 시나리오 ERD | Flyway V3 설계 기준 제공 |
| 3 | 인덱스 설계 | 목록/검색/정합성 성능 기준 제공 |
| 4 | 공통 응답/에러코드 | REST API 구현 일관성 확보 |
| 5 | M2 시나리오 API | 컨트롤러/서비스/매퍼 작업 기준 제공 |
| 6 | 감사로그/입력검증 표준 | 관리자 기능 구현 시 보안 기준 내재화 |
| 7 | M2 작업지시서 | 구현 순서, 파일 위치, 검증 방법 명시 |

## 4. 남은 후속 설계

- M3 챗봇 런타임: 대화 세션, 상태 전이, 실패 처리, 만족도 평가
- M4 검색: FTS/trgm 점수식, 유사어 확장, 인기 검색어 집계
- M5 크롤링: robots.txt, SSRF 방어, 파싱 규칙, 스케줄 충돌 방지
- M6 운영: 대시보드 지표, 로그 보존, 백업/복구, 알림 임계값
- M7 보안/접근성: OWASP ASVS 매핑, 위협모델, 접근성 체크리스트
