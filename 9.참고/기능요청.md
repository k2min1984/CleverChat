# 시나리오 챗봇 시스템 구축 요구사항

## 1. 개발 환경 및 기술 스택

* Backend

  * Java Spring Boot
  * Spring Security
  * JPA/MyBatis
  * PostgreSQL

* Frontend

  * Thymeleaf
  * HTML5/CSS3/JavaScript
  * 반응형 웹 지원

* 기타

  * REST API 기반 구조
  * Git 기반 형상관리
  * 환경(dev/stage/prod) 분리 운영

---

## 2. 주요 기능

### 2.1 시나리오 챗봇

* 시나리오 기반 챗봇 제공
* 단계별 질문/답변 흐름 구성
* 버튼 선택형 시나리오 진행 지원
* 자유 텍스트 입력 기반 검색 지원
* 추천 질문 제공
* 답변 만족도 평가 기능
* 답변 실패 시 예외 처리 및 관리자 확인 가능
* 이전 대화 이력 조회 기능
* 카테고리별 시나리오 관리

* 시나리오 검색 기능
