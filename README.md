# CleverChat

시나리오 상담, 검색, 웹 크롤링을 제공하는 챗봇 시스템입니다. Spring Boot, MyBatis, PostgreSQL을 사용합니다.

## 설치 및 실행

아래는 **Windows 로컬 개발 환경** 기준입니다.

### 1. 준비

- 저장소 전체를 내려받아 압축을 풉니다.
- **JDK 17**을 설치하고 `JAVA_HOME`을 지정합니다.
- **Docker Desktop**을 설치하고 Linux containers 모드로 실행합니다.

Maven과 PostgreSQL은 따로 설치하지 않아도 됩니다. 처음 실행할 때 필요한 파일을 다운로드하므로 인터넷 연결이 필요합니다.

### 2. 실행

이 README가 있는 폴더에서 PowerShell을 열고 아래 명령을 실행합니다.

```powershell
& '.\3.개발\cleverchat\start-local.cmd'
```

파일 탐색기에서 `3.개발 → cleverchat → start-local.cmd`를 더블클릭해도 됩니다.

**DB 준비, 빌드, 테이블·기본 데이터 구성과 서버 실행**을 자동으로 처리합니다. 새 설치라면 사용할 관리자 ID와 비밀번호를 입력합니다. ID는 영문/숫자로 시작하는 3~50자(점·밑줄·하이픈 허용), 비밀번호는 12자 이상입니다. 기존 DB가 있으면 기존 계정을 사용합니다.

### 3. 접속

실행 창에 `READY`와 `health UP`이 나오면 접속합니다.

| 화면 | 주소 |
|---|---|
| 관리자 로그인 | http://127.0.0.1:8080/login |
| 상담 | http://127.0.0.1:8080/chat |
| 시스템 설정 | http://127.0.0.1:8080/admin/system-settings |

사용하는 동안 실행 창을 열어 두고, 종료할 때는 **Ctrl+C**를 누릅니다. DB 데이터는 유지되며 다시 실행할 때도 같은 명령을 사용합니다.

## 처음부터 준비되는 것

기본 메뉴, 공통코드, 역할·권한, 시스템 설정과 최초 관리자 계정이 준비됩니다. [기본 데이터 목록](3.개발/cleverchat/deploy/seed/README.md)에서 구성을 확인할 수 있습니다.

시나리오와 크롤링할 사이트는 설치 후 등록합니다. JSON 저장 위치, 크롤링 옵션, vLLM 연결 및 독립/연계 로그인 방식은 **시스템 설정**에서 관리합니다. 동적 게시판 수집과 외부 연계는 아래 상세 안내의 추가 설정이 필요합니다.

## 실행이 안 될 때

| 증상 | 확인할 내용 |
|---|---|
| Java 관련 오류 | JDK 17과 `JAVA_HOME` 설정 후 새 PowerShell에서 실행 |
| Docker 연결 오류 | Docker Desktop이 실행 중이고 Linux containers 모드인지 확인 |
| 8080 포트 사용 중 | 이미 실행한 서버를 이용하거나 종료 후 다시 실행 |
| DB 접속·빌드·시작 오류 | 실행 창의 `[STOP]` 메시지와 `3.개발/cleverchat/logs` 확인. [상세 문제 해결](5.배포/02.환경구축가이드/환경구축_배포가이드.md#자동-실행-문제-해결) 참고 |
