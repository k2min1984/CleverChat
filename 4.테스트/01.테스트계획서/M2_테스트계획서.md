# M2 테스트 계획서

> 작성일: 2026-05-08

## 범위

- 시나리오 카테고리 CRUD
- 시나리오 CRUD와 논리 삭제
- 버전 생성/그래프 저장/게시/활성화
- 키워드/유사어 저장
- 권한/입력검증/감사로그
- OPERATOR 비활성 시드와 최초 비밀번호 변경 강제
- 쿠키 보안 속성, 프록시 헤더, 매칭 캐시 TTL 설정 기준

## 테스트 유형

| 유형 | 도구 | 기준 |
|---|---|---|
| 단위 테스트 | JUnit5, Mockito | 서비스 업무 규칙 |
| 통합 테스트 | Spring Boot Test, PostgreSQL Testcontainers 권장 | Mapper/Flyway/트랜잭션 |
| 화면 점검 | 브라우저 수동 | 관리자 주요 흐름 |
| 보안 점검 | 수동 + Spring Security 테스트 | 권한, CSRF, 입력검증, 쿠키 속성 |
| 회귀 테스트 | Spring Boot Test + 수동 | M1 로그인/세션/잠금, V3.1 인증 컬럼 영향 |
| 운영 설정 점검 | 설정 리뷰 + stage 기동 로그 | `forward-headers-strategy`, prod 전용 부팅 경고, 캐시 TTL 300초 |

## 완료 기준

- `mvn test` 성공
- 시작 노드 없는 게시 실패 테스트 통과
- 게시 버전 직접 수정 방지 테스트 통과
- ADMIN/OPERATOR 외 접근 차단 확인
- 상태 변경 감사 로그 확인
- Flyway V3.1 적용 후 `users.must_change_password` 기본값 확인
- OPERATOR 시드가 `enabled=false`, `must_change_password=true`로 생성되는지 확인
- 세션성 쿠키 `SameSite=Lax`, `Secure=true`, `HttpOnly=true` 확인. CSRF 토큰 쿠키는 `HttpOnly=false` 예외 확인
- `server.forward-headers-strategy=framework` 적용 및 prod 프로파일 전용 부팅 경고 로그 확인
- 매칭 캐시 TTL 기본값 300초 확인
