# M2 테스트 시나리오

> 작성일: 2026-05-08

| ID | 시나리오 | 기대 결과 |
|---|---|---|
| M2-TC-001 | ADMIN이 시나리오를 생성한다 | 201 또는 저장 성공, 목록 노출 |
| M2-TC-002 | OPERATOR가 시나리오를 수정한다 | 수정 성공, 감사 로그 저장 |
| M2-TC-003 | 권한 없는 사용자가 `/admin/scenarios` 접근 | 403 또는 로그인 요구 |
| M2-TC-004 | 제목 없이 생성 요청 | 400 검증 오류 |
| M2-TC-005 | 초안 버전을 생성하고 노드 그래프 저장 | 노드/옵션 저장 |
| M2-TC-006 | 시작 노드 없이 게시 | 400 `SCENARIO_INVALID_NODE_GRAPH` |
| M2-TC-007 | 게시된 버전을 활성화 | 시나리오 상태 ACTIVE |
| M2-TC-008 | 활성 시나리오 삭제 요청 | 비활성화 선행 요구 또는 상태 충돌 |
| M2-TC-009 | 키워드/유사어 일괄 저장 | 기존 데이터 갱신, 중복 방지 |
| M2-TC-010 | 삭제된 시나리오 상세 조회 | 404 또는 삭제 상태 표시 정책 적용 |
| M2-TC-011 | Flyway V3.1 적용 후 `users.must_change_password` 컬럼 확인 | 컬럼 기본값은 `false`, 기존 ADMIN 계정은 비밀번호 변경 강제 대상이 아님 |
| M2-TC-012 | 초기 OPERATOR 시드 확인 | 계정은 `enabled=false`, `must_change_password=true`로 생성되어 즉시 권한 행사 불가 |
| M2-TC-013 | 비밀번호 변경 강제 대상 사용자가 `/admin/**` 접근 | `/admin/password-change`로 유도되고 변경 완료 후 `must_change_password=false` |
| M2-TC-014 | 쿠키 보안 속성 확인 | 세션성 쿠키는 `SameSite=Lax`, `Secure=true`, `HttpOnly=true`; CSRF 토큰 쿠키는 `HttpOnly=false` 예외 |
| M2-TC-015 | 프록시 헤더와 매칭 캐시 TTL 설정 확인 | `server.forward-headers-strategy=framework`, prod 프로파일에서만 부팅 경고 로그, 캐시 TTL 기본값 300초 |
