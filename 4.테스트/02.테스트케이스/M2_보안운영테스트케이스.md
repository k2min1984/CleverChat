# M2 보안/운영 테스트케이스

> 작성일: 2026-05-08  
> 범위: M2 구현 전 문서 초안. `application-*.yml`, Actuator, 기동 로그 점검 절차 기반  
> 관련 문서: [보안 체크리스트](../../2.설계/05.보안설계서/보안체크리스트.md), [M2 운영 메모](../../2.설계/06.운영메모/M2_운영메모.md), [M3 사용자 화면 목록](../../2.설계/01.화면설계서/M3_사용자화면목록.md)

## 1. 전제

- M2 시나리오 구현 코드는 아직 시작하지 않는다.
- 설정 파일은 `3.개발/cleverchat/src/main/resources/application.yml`, `application-dev.yml`, `application-stage.yml`, `application-prod.yml`을 기준으로 한다.
- Actuator 노출 기준은 공통 `health,info`, prod `health`다.
- `server.forward-headers-strategy=framework`는 공통 설정에 존재한다.
- prod 전용 프록시 헤더 부팅 경고 로그는 현재 미구현 기준이며, M2 구현 후 로그 클래스/문구가 확정되면 기대 결과를 갱신한다.

## 3. 실행 메모

- dev 로컬 검증은 `3.개발/cleverchat`에서 수행한다.
- prod 프로파일 테스트는 실제 운영 DB가 아닌 격리된 검증 DB와 운영형 환경변수를 사용한다.
- Actuator 테스트는 인증/네트워크 정책이 확정되면 접근 제어 기대값을 보완한다.
- M2 구현 후 실제 API 경로와 로그 문구가 확정되면 `M2-OPS-TC-010`, `M2-OPS-TC-012`, `M2-OPS-TC-014`, `M2-OPS-TC-015`의 보류 문구를 실행 가능한 절차로 갱신한다.
